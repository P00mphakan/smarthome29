========================================================================

1. ขั้นตอนเตรียมการ (ทำครั้งแรกครั้งเดียว):
   1.1 ดับเบิ้ลคลิกไฟล์ "install_requirements.bat" เพื่อติดตั้ง OpenCV สำรอง
   1.2 ดาวน์โหลดโปรแกรมฟรี cloudflared สำหรับ Windows จาก:
       https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
   1.3 เปลี่ยนชื่อไฟล์ที่ดาวน์โหลดมาเป็น: "cloudflared.exe" 
       แล้วนำมาวางไว้ในโฟลเดอร์นี้: C:\Users\IOT WIN10\Smart Home29\

2. วิธีเปิดใช้งาน:
   - ดับเบิ้ลคลิกที่ไฟล์ "start_all.bat"
   - หน้าต่าง CMD สองอันจะเปิดขึ้นมาทำงานคู่กัน:
     1) เซิร์ฟเวอร์กล้อง (Snapshot ทุก 1 นาที + 1080p Video)
     2) Cloudflare Tunnel ที่จะสร้างลิงก์ HTTPS ให้อัตโนมัติ

3. การเชื่อมต่อกับเว็บ Vercel:
   - สังเกตในหน้าต่าง Cloudflare Tunnel จะมีลิงก์ เช่น:
     https://xxxx-xxxx.trycloudflare.com
   - เปิดหน้าเว็บ Smart Home บนมือถือ/iPad/Vercel
   - กดปุ่ม ⚙️ (ฟันเฟือง) ที่มุมบนขวาของการ์ดกล้อง
   - วางลิงก์ Cloudflare ลงไป แล้วกด บันทึก
   - หน้าเว็บจะเริ่มดึงภาพ Snapshot ทุก 1 นาทีอัตโนมัติ และกดดูสด 1080p ได้ทันที!
